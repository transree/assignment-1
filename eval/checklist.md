# 判定の基準

Skill の報告1回分を、次の項目で判定する。すべて満たせば合格。
項目ごとに、コードで判定するか人が判定するかを `(コード)` `(人)` で書く。

## 最低限の項目(課題で決まっている)

- [ ] (コード)実行したコマンドが書いてある
- [ ] (コード)合格と不合格の数が書いてあり、記録の中の pytest の出力と合う
- [ ] (人)落ちたテストの名前とエラーが書いてある(落ちたテストがないときは、ないと書いてある)
- [ ] (人)落ちた理由の見立てが、事実と分けて推測として書いてある
